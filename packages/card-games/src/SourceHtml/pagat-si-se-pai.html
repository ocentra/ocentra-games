Sì Sè Pái

Four Colour Cards

Sì Sè Pái (四色牌) is the name for Chinese four colour chess cards and the game played with them. The equivalent cards and game are known in Vietnam as Tứ Sắc. The pack contains 28 cards of each colour (green, white, yellow, red) depicting the seven Chinese chess pieces, and there are four identical copies of each card. In addition to these 112 cards there may be several extra cards (jokers).

The game is a draw and discard game slightly reminiscent of Mah Jong. Detailed rules can be found on this archive copy of Wei-Hwa Huang's Si Se Pai page, and another set on a Se Se Pai page by 'tnt'. The Vietnamese version is also described on the Vinagames site.
