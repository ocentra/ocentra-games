Polignac & Knaves

These are games in which there is a penalty for each knave taken in tricks.

There were rules on Dave Barker's web site. Here is an archive copy of his Knaves page.

Also, there were rules in French on Jean-François Bustarret's page Polignac (ou jeu des Valets) (archive copy).

You can download a freeware Polignac program from Thanos Card Games.
