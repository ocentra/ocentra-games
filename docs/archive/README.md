# Documentation Archive

This folder stores superseded planning, migration, handoff, and one-off audit docs that no longer represent the current codebase.

## Purpose

- Keep historical context without polluting active docs.
- Make it clear which docs are no longer canonical.
- Provide replacement links to active documentation.

## Archive Index

See:

- `docs/archive/INDEX.md`

## Rules

- Archived docs are read-only.
- New work must not target archived docs.
- If a file is archived, add a replacement canonical path in the index.
